Publish the run manifests and confine contributor identifiers

Ten manifests, one per driver, recording the commit that produced the reported
results, a clean working tree, the interpreter, the platform, the seed and the
parameter values behind each run. They agree with each other and with the
record freeze, so a reader can tie any reported estimate to the code state
that produced it.

Depositing the release for a citable identifier means naming the authors, and
a deposit cited in a paper cannot have anonymous creators. The names are
therefore confined to the two citation files, and a test fails if a
contributor identifier appears anywhere else in the tree.
